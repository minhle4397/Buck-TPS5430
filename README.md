# DC-DC-Buck-Converter-Power-Board
This project features the design and implementation of a compact, high-efficiency power distribution board tailored for autonomous mobile robots (AMR). The system converts a 12VDC input into two stable regulated rails: 5V (3A) for logic/sensors and 3.3V for microcontrollers.
